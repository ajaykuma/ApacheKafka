# ApacheKafka

Hands-on Apache Kafka work covering cluster setup, Kubernetes/EKS & Docker deployment, monitoring, and client APIs across Java, .NET, and Python.
For applied stream-processing projects and consulting-style examples, see [Kafka_Work_n_exmpls](https://github.com/ajaykuma/Kafka_Work_n_exmpls).

> 🚧 This repository is currently being refined and improved. Stay tuned!

## Before You Start
- Please read through each example file completely before running it — setup steps or prerequisites are often noted inline.
- Scripts/configs are periodically updated and may need adjustment depending on the Kafka version you're using (check the version noted at the top of each file, if present).
- Any datasets referenced here can be found in my [Datasets_For_Work](https://github.com/ajaykuma/Datasets_For_Work) repository.

## What's Here
- **Cluster setup & CLI** — Getting a Kafka cluster running and managing it via CLI
- **Kubernetes / EKS & Docker** — Deploying and running Kafka on Kubernetes (EKS) and via Docker
- **Monitoring** — Cluster and topic monitoring setups
- **Client APIs** — Producer/consumer examples in Java, .NET, and Python
