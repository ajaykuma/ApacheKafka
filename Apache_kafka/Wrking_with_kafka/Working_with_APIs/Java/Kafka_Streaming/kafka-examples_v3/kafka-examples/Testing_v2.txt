Conclusion:
You should see read_uncommitted=4, read_committed=3. That one record difference is the entire EOS guarantee — ORD-TXN-003 
physically exists on the broker but is completely invisible to any consumer using isolation.level=read_committed.

Output:
--demonstration of exactly-once semantics
read_committed — 3 records:
ORD-TXN-001  partition=1  offset=0 
ORD-TXN-002  partition=0  offset=0 
ORD-TXN-004  partition=0  offset=2 
read_uncommitted — 4 records:
ORD-TXN-001  partition=1  offset=0 
ORD-TXN-002  partition=0  offset=0 
ORD-TXN-003  partition=2  offset=0  ← this is the aborted record
ORD-TXN-004  partition=0  offset=2 

Three things worth noting:
1. ORD-TXN-003 physically exists on the broker — it's on partition=2 offset=0. The data was written. But read_committed consumers 
cannot see it because the transaction was aborted. It's not deleted, it's just fenced off.
2. The offset gap on partition=0 — offsets go 0, then 2. Offset=1 is missing because that's where ORD-TXN-003's transaction marker sits. 
Kafka uses internal markers to track transaction boundaries, which consume offset slots.
3. This is why isolation.level matters in production — if any of your consumers are reading topics written by transactional producers and 
you don't set read_committed, you risk processing aborted records. Your default is read_uncommitted.

Conclusion:
What just happened in the processor:

Read ORD-TXN-002 at partition=0 offset=0 → processed → offset atomically committed to 1
Read ORD-TXN-004 at partition=0 offset=2 → processed → offset atomically committed to 3
Read ORD-TXN-001 at partition=1 offset=0 → processed → offset atomically committed to 1
ORD-TXN-003 was never seen — isolation.level=read_committed filtered it out before it even reached the poll loop

Notice offset=2 for ORD-TXN-004 on partition=0 — offset=1 was consumed by the abort marker for ORD-TXN-003. 
The processor jumped straight from 0 to 2 without any special handling — Kafka managed the gap transparently.

Concept							Proven

sendOffsetsToTransaction			Offset + output commit are one atomic operation
